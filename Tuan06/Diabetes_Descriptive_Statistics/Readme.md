# Thống kê mô tả dữ liệu về bệnh tiểu đường
## Quá trình thực hiện

### Bước 1: Khám phá dữ liệu

- Đọc dataset gồm 768 dòng và 9 cột.

- Kiểm tra kiểu dữ liệu, giá trị thiếu và trùng lặp.

- Phân tích các giá trị 0 bất thường.

### Bước 2: Thống kê mô tả

- Tính Mean, Median, Mode.

- Tính Variance, Standard Deviation.

- Tính Min, Max, Range, Percentile.

- Tính Q1, Q2, Q3 và IQR.

- Lập bảng thống kê tổng hợp.

### Bước 3: Trực quan hóa dữ liệu

- Countplot: Phân bố nhãn Outcome.

- Histogram: Phân bố các thuộc tính.

- Boxplot: Phát hiện giá trị ngoại lai.

### Bước 4: Phân tích kết quả

- So sánh các chỉ số thống kê.

- Phân tích sự khác biệt giữa Outcome = 0 và Outcome = 1.

- Nhận xét chất lượng dữ liệu và đưa ra kết luận.
