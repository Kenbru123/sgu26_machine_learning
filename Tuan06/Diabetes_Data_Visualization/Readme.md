# Trực quan hóa dữ liệu bệnh tiểu đường
## 1. Công cụ sử dụng
- Python, Jupyter Notebook
- Pandas, NumPy
- Matplotlib, Seaborn

## 2. Quá trình thực hiện

#### Bước 1: Khám phá dữ liệu
- Đọc dataset và kiểm tra cấu trúc dữ liệu.
- Xác định các thuộc tính và nhãn Outcome.

#### Bước 2: Trực quan hóa bằng Matplotlib
- Vẽ Bar Chart thể hiện số lượng mẫu theo Outcome.
- Tùy chỉnh tiêu đề, màu sắc, nhãn trục và giá trị trên biểu đồ.

#### Bước 3: Trực quan hóa bằng Seaborn
- Countplot và Barplot: Phân tích số lượng mẫu và giá trị trung bình.
- Pie Chart: Thể hiện tỷ lệ phân bố Outcome.
- Histogram: Phân tích phân bố các thuộc tính.
- Boxplot và Violin Plot: Quan sát sự phân tán và giá trị ngoại lai.

#### Bước 4: Phân tích mối quan hệ giữa các thuộc tính
- Scatter Plot: Khảo sát mối quan hệ giữa Glucose và BMI.
- Correlation Heatmap: Phân tích hệ số tương quan giữa các thuộc tính.

#### Bước 5: Nhận xét và kết luận
- Phân tích kết quả từ các biểu đồ.
- So sánh đặc điểm dữ liệu giữa hai nhóm Outcome.
- Nhận diện các giá trị bất thường và rút ra kết luận.
